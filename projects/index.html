Projects

一些平时写着玩的开源小工具。

  • video-reader

    搬家那会儿对象让我研究一下哪个牌子的洗衣机最值得买。我懒得一个一个点开 B 站视频慢慢看, 就干脆写了这个工具替我看: 给它一个主题, 它会自动去 B 站搜相关视频, 抓下字幕, 交给 LLM 提炼事实, 最后合成一份可读的调研报告。从此"帮我查一下市面上的洗衣机哪个比较好"变成了敲一行命令的事。

  • home-mapper

    和对象在上海找房那阵子做的。每看到一个候选小区都得手动查它到我俩公司的地铁通勤时间, 于是我把上海所有地铁站到我们两个公司的通勤时间提前算好, 叠在 Leaflet 地图上。每个潜在的地铁站自动查询高德地图通勤时间, 一眼就能看出这个小区值不值得约看房。之后找房效率提高了大概一个量级。后来打算把房租数据也接进来的，结果被贝壳的反爬技术吓晕，作罢。

  • git-byline

    有一天我翻自己的 GitHub 主页, 发现那张贡献热力图看起来冷冷清清, 但其实我写的（并非我写，Claude Code罢了）（你知道吗这个网页也是CC写的）代码并不少——只是习惯攒一堆改动再一次性 commit 上去, 小方块就变得很稀疏。有点不服气, 就写了这个工具: 它按"每天新增多少行代码"重新画贡献图, 让我的实际工作量能更诚实地呈现出来。默认的 GitHub 风格绿格子配色也保留了。不过做完了发现和 GitHub 上的贡献图长得差不多。不是Github的问题，是我肝功能的问题。

  • poi-marker

    我的小红书里有一百万亿个收藏, 全烂在里面, 想去吃饭的时候找不到, 种草了又吃不上。所以我做了这个轻量的移动端地图: 能往上打点、写备注、分颜色。技术栈是 Vue 3 + FastAPI + 高德地图；但是适配移动端网页开发真的太难搞了，项目半死，哪天头铁了再回来接着搞。

  • Triplet-Network

    本科时期对论文 Deep Metric Learning Using Triplet Network 的一次复现, 也是我写的第一个深度学习项目。现在看看代码质量相当辣眼睛, 但当时折磨师兄一整天之后，终于跑通结果的感觉可能会记一辈子。

  • Batch-CEA

    更早期的一个 MATLAB 小工具, 对 NASA 的 Chemical Equilibrium Application 做了批处理改进。大一在火箭推进方向的实验室打工顺手写的。
